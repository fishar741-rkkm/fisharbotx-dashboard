FisharBotX Documentation 📖

This guide explains how to use the FisharBotX platform, including Dashboard and all pages.

Dashboard

The Dashboard provides quick access to bot status, database connection, and interactive buttons (Refresh, Open Bot, Check Status, Dark/Light Mode, Notifications).

Login & Register

Users can Login or Register with their email and password. Data is stored in SQLite database.

Admin Panel

The Admin page allows administrators to manage users and view system status.

Pricing

The Pricing page shows available subscription plans.

FAQ

The FAQ page answers common questions about FisharBotX.

Legal Pages

  • Terms of Service
  • Privacy Policy
  • Contact

API Docs

For developers, see API Docs with endpoints for Register and Login.

Security

Security headers are configured in vercel.json to protect against common attacks.

SEO

Meta tags, robots.txt, and sitemap.xml are included for search engine indexing.
