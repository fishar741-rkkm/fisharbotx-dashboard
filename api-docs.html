FisharBotX API Documentation 🚀

Welcome to the FisharBotX API. Below are the available endpoints:

Register User

POST /register

Request Body:
{
  "name": "User Name",
  "email": "user@example.com",
  "password": "123456"
}

Response:
{
  "id": 1,
  "name": "User Name",
  "email": "user@example.com"
}

Login User

POST /login

Request Body:
{
  "email": "user@example.com",
  "password": "123456"
}

Response:
{
  "message": "Login successful",
  "user": {
    "id": 1,
    "name": "User Name",
    "email": "user@example.com"
  }
}

Notes

  • All requests should be sent as JSON.
  • Server runs locally on http://localhost:4000.
  • Future versions will include token-based authentication.
